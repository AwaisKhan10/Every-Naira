# Every Naira Has a Job

Frontend demonstration of a product, costing, pricing, inventory, and orders workspace. There is no backend. Records stay in this browser.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the marketing site and [http://localhost:3000/dashboard](http://localhost:3000/dashboard) for the sample business, Adaeze Collective.

```bash
npm test
npm run lint
npm run typecheck
npm run build
```

## What is simulated

Payments, refunds, checkout, WhatsApp, email, and provider connections do not leave the browser. Jumia and Konga fees are editable samples, not official tariffs. The admin role switch is not production security. Share links only resolve in this browser.

Use **Reset demo data** in the profile menu to restore the original sample.
